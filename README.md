# Test task for Crafttecth (Crafttecth CanvasTest)

***Requirements:***
1. Use Vite to set up a React + TypeScript application and integrate the Konva.js library.
2. Create a full-screen canvas. Add functionality to make the canvas infinite, allowing it to be dragged in any direction.
3. Implement a toolbar in any part of the screen with the following features:
   - **Button 1**: A dropdown menu containing three shapes that can be added to the canvas after selection.
   - **Button 2**: A cursor tool to interact with added shapes (e.g., dragging them across the canvas).

***Deadline: 2 days***

### **Implemented Features**

1. **Shape Selection**: 
   - A dropdown menu with three shapes: square, triangle, and circle.
   - Selected shapes can be added to the canvas.
2. **Cursor Tool**: 
   - A "Cursor" button for switching to a tool that allows dragging the canvas and shapes.
3. **Infinite Canvas**: 
   - An infinite canvas that can be moved using the cursor.
4. **Clear Canvas**: 
   - A "Clear Canvas" button to reset the canvas.
